Studio Rider Receiver v0.3.0

A free, unofficial VST3 plugin for receiving and playing audio streams from Studio Rider v1.0 directly inside your DAW.

This is the first release. It has worked in initial tests, but has not yet been extensively tested.

Feedback, bug reports and suggestions are welcome via the Issues tab on this repository.

Compatibility

- macOS (Apple Silicon)
- VST3 format
- Pro Tools via a VST3 host such as Blue Cat PatchWork

This is an independent companion plugin, not the original Studio Rider application.
